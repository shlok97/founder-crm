# Reporting a security issue

Please use this repository's **Security → Report a vulnerability** feature when available. Otherwise contact the maintainer through their GitHub profile before sharing details. Do not post credentials, private messages or customer records in a public issue.

This starter is intended for a single user's local machine. The dashboard binds to loopback and has no remote user authentication. Expose only the dedicated webhook route through an explicitly configured relay. See [integration setup](docs/integrations.md) for what each optional connector reads or sends.
